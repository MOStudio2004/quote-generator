# ☕ Quote Generator

**A little inspiration, a little laughter, and the right words for the moment.**

A beautifully designed Quote Generator that brings you random quotes to inspire your day. Featuring a warm coffee-inspired color palette, smooth typing animations, and a clean, responsive interface.

## ✨ Features

- **Random Quotes:** Discover a new quote with every click.
- **Author Display:** See the author alongside each quote.
- **Copy to Clipboard:** Copy your favorite quotes with a single click.
- **Typing Animation:** Enjoy an animated headline.
- **Responsive Design:** Adapted for desktop and mobile screens.
- **Coffee-Inspired Theme:** A warm gradient palette inspired by espresso, mocha, and caramel.
- **Loading Feedback:** Get visual feedback while a new quote is being fetched.

## 🛠️ Built With

- [React](https://react.dev/) — UI development
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- [Vite](https://vite.dev/) — Development server and build tool
- CSS3 — Styling, gradients, animations, and responsive layouts
- [DummyJSON Quotes API](https://dummyjson.com/docs/quotes) — Random quote data

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd quote-generator
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🌐 API

This project uses the DummyJSON Quotes API to retrieve random quotes and their authors.

Endpoint: `https://dummyjson.com/quotes/random`

## 🎯 Project Goal

The goal of this project is to practice building interactive React components, working with asynchronous API requests, managing state with React Hooks, using TypeScript types, and creating responsive user interfaces with CSS.
